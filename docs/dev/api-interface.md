### リクエスト / レスポンス例

#### `GET /api/v1/{resource}`

**リクエスト**:

```
GET /api/v1/{resource}?page=1&limit=20
Authorization: Bearer {token}
```

**レスポンス（200 OK）**:

```json
{
  "data": [
    {
      "id": "{id}",
      "name": "{name}"
    }
  ],
  "total": 0,
  "page": 1,
  "limit": 20
}
```

#### `POST /api/v1/{resource}`

**リクエスト**:

```json
{
  "name": "{name}",
  "description": "{description}"
}
```

**レスポンス（201 Created）**:

```json
{
  "id": "{id}",
  "name": "{name}",
  "description": "{description}",
  "created_at": "2024-01-01T00:00:00Z"
}
```
